# 🌟 Meow World — Product Vision & Philosophy

**Version:** 1.0  
**Date:** 2026-09-01  
**Status:** Core Vision Defined

---

## 🎯 Vision Statement

> **Meow World คือ Visual World ที่เชื่อมโยงกับชีวิตจริง — ไม่ใช่โลกเสมือนที่มาแทนชีวิตจริง แต่เป็นพื้นที่ดิจิทัลที่ช่วยให้เรื่องราว ความสัมพันธ์ และความทรงจำจากชีวิตจริงมีตัวตนต่อไป**

---

## 🏛️ Core Design Principles

### 1. Free First
คุณค่าหลักของ Meow World ต้องเข้าถึงได้โดยไม่สร้างกำแพงตั้งแต่เริ่มต้น

### 2. Value Before Revenue
สร้างคุณค่าให้ผู้ใช้ก่อน รายได้ควรเป็นผลพลอยได้จากคุณค่าที่เกิดขึ้น

### 3. Visual First
ให้ภาพและบริบทช่วยสื่อสารแทนข้อความเมื่อเหมาะสม

### 4. Let the World Tell the Story
> **"ให้ภาพมันเล่าเรื่อง"**

### 5. Data Should Tell the Story
ข้อมูลที่สะสมตามเวลาควรสะท้อนประวัติและพฤติกรรมจริง

### 6. Evaluate Privately
ระบบสามารถประเมินภายในโดยไม่เปิดเผยคะแนนดิบ

### 7. Rank Without Shaming
การจัดอันดับไม่ควรทำให้คนรู้สึกว่าตัวเอง "ด้อยกว่า" จากคะแนน

### 8. Preserve Credit
การต่อยอดไม่ควรลบคุณค่าของต้นฉบับ ทุก Contribution ควรมีที่มาที่ไป

### 9. Real Life First
Meow World เป็นส่วนต่อขยายของชีวิตจริง ไม่ใช่สิ่งที่ต้องมาแทนชีวิตจริง

### 10. Memories Have Value
ข้อมูลบางอย่างไม่ได้มีคุณค่าเพราะนำไปวิเคราะห์ได้ แต่มีคุณค่าเพราะวันหนึ่งเจ้าของอยากกลับมาดูมันอีกครั้ง

## 🌍 Visual World Principle

หลักการสำคัญของ UX คือ

> **"ให้ภาพมันเล่าเรื่อง"**

แทนที่จะให้ระบบใช้ข้อความอธิบายทุกอย่าง ผู้ใช้ควรสามารถเข้าใจสถานะ ความสัมพันธ์ กิจกรรม และคุณค่าบางส่วนจากสิ่งที่มองเห็นได้

### Visual Language

| Symbol | Meaning |
|--------|---------|
| 🏠 | Home |
| 🐱 | Pet |
| ❤️ | Relationship / Favorite / Affection |
| 🎉 | Event |
| 📚 | Knowledge / Meow Wiki |
| 🛍️ | Marketplace |
| 💬 | Community |
| 📖 | Life Journey / Journal |
| 🔒 | Private |
| 🌱 | Growth / Development |

> **Don't make users learn the interface. Let the interface become the world.**

## 🏠 Home = "บ้านเลขที่" ของผู้ใช้

Home ไม่ใช่เพียงพื้นที่ตกแต่ง แต่เป็นจุดหนึ่งในโลกของ Meow World

### Home ทำหน้าที่เป็น

- **Personal Space** — พื้นที่ส่วนตัว
- **Identity** — ตัวตนของผู้ใช้
- **Social Space** — พื้นที่ทางสังคม
- **Discovery** — การค้นพบ
- **Inspiration** — แรงบันดาลใจ

### Key Concept

> **การเห็นบ้านของผู้อื่นควรก่อให้เกิดแรงบันดาลใจโดยธรรมชาติ**

เช่น "อ๋อ บ้านตกแต่งแบบนี้ได้ด้วยเหรอ"

## 👥 User ID vs Home ID

### User ID
- ใช้เป็นตัวตนระดับผู้ใช้
- เชื่อมโยงกับ: บทความ, Community, Marketplace, Contribution, Activity
- ยังมีประโยชน์แม้ยังไม่มี Home

### Home ID
- ใช้ระบุตัว Home โดยเฉพาะ
- รองรับ 1 User = Multiple Homes
- แต่ละ Home มี Privacy Settings แยกกัน

## 💎 Emotional Design

### Life Journey = Flashback / Remembrance

ไม่ใช่ "ระบบกำลังบอกว่าคุณสูญเสียสัตว์เลี้ยง"

แต่เป็น "คุณกำลังย้อนกลับไปดูชีวิตที่เคยมีร่วมกัน"

### Guiding Words

> **"ขอบคุณสำหรับทุกวันที่เราได้อยู่ด้วยกัน"**

### Principle

> **ปล่อยให้ความทรงจำจริงเป็นผู้เล่าเรื่อง**

## 🏆 Evaluation Philosophy

### Core Principle

> **Evaluate Privately. Rank Publicly. Explain Contextually.**

### What We Evaluate

- รูปแบบข้อมูลมีความสม่ำเสมอหรือไม่?
- มีประวัติและสอดคล้องกับบริบทหรือไม่?

### What We Don't Do

- ไม่พยายามตอบว่า "คนนี้เป็นคนดีหรือไม่?"
- ไม่เปิดเผยคะแนนดิบ
- ไม่สร้างแรงกดดันด้วยการเปรียบเทียบ

### Key Insights

- **จำนวนข้อมูล ≠ คุณภาพ**
- **ความถี่ของข้อมูล ≠ ความใส่ใจ**
- **รูปแบบของข้อมูลเมื่อวางลงบนเวลา = Quality Signal**

## 🌐 Metaverse Philosophy

Meow World ไม่ใช่โลกที่ผู้ใช้ต้องเข้าไปอยู่ตลอดเวลา

แต่เป็น:

> **โลกดิจิทัลที่ผู้ใช้สามารถกลับเข้าไปหาได้เมื่ออยากพบคน พบสัตว์เลี้ยง พบกิจกรรม หรือกลับไปหาความทรงจำ**

### Connection

```
REAL LIFE
    ↓
Photos / Memories / Events / Records
    ↓
🌎 MEOW WORLD
    ↓
Home / Town / Community / Life Journey
```

> **Tamagotchi 4.0 with Real Life**
